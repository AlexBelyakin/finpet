# Питомец Финни (FinPet)

Игровой сервис финансовой грамотности для детей **7–11 лет**. Прототип по ТЗ
Департамента финансов города Москвы.

Ребёнок заботится о питомце: делит монеты на **нужное**, **желаемое** и **копилку**.
Настоящих денег, рекламы, аккаунтов и сервера нет. Профиль хранится только на устройстве.

- Репозиторий: **https://github.com/AlexBelyakin/finpet** (private)
- Ветки: `Alex` (Александр), `Ilya` (Илья), `main` (общее готовое)
- Стек: **Flutter / Dart 3.13 · Material 3**
- Основной запуск сейчас: **Android Studio + эмулятор** (API 26+)
- Дополнительно: web-server `http://127.0.0.1:8080`

Имя на устройстве: **Питомец Финни**. Пакет пока `com.example.finpet`.

## Что умеет прототип сейчас

Заставка (логотип, без 3D) → знакомство («Это игра про монеты») → создание питомца
(кот / лис / птица, цвета персик / мята / небо / волна) → дом.

Дом в стиле HUD вокруг питомца (комната + 3D-модель на полу):

| Элемент | Что видно |
|---|---|
| Питомец | Одна GLB-модель `assets/models/finni.glb`, стоит на месте, без вращения и автоанимации |
| Монеты / копилка | Счётчики сверху |
| Громкость | Иконка звука → шторка: тише / громче / выкл |
| План, задания, покупки, копилка | Крупные цветные круги по бокам |
| Игры и прогресс | Снизу слева |
| Настроение, сытость, цель | Кольца с процентом справа снизу |
| Текущее задание | Плашка, если есть невыполненное |
| Взрослым / словарь / закрыть неделю | Сверху справа (неделя — в демо-режиме) |

С дома открываются экраны:

- **Игры** — пять мини-игр; награда **не в копилку**, потолок **80 монет за неделю**
  - «Надо или хочу?»
  - «Лови монетки»
  - «Три баночки»
  - «Копилка ловит»
  - «Найди пары»
- **План** — разложить монеты: нужное / желаемое / копилка (нужное не меньше 15); кольца показывают долю
- **Задания** — сценарии по темам план / копилка / покупки
- **Покупки** — нужное (корм, вода, уход) и желаемое; без плана купить нельзя, в минус уйти нельзя
- **Копилка** — цель, положить / снять, кольцо до цели
- **Прогресс** — **одно** круговое кольцо до цели, задания, последняя неделя, история монет
- **Взрослым** — вход `8 + 5 = 13`: демо-недели, сброс профиля, сводка
- **Словарь** — короткие подсказки по терминам
- **Музыка** — два трека по кругу (`track_1.mp3`, `track_2.mp3`)

Карточки и кнопки слегка сжимаются при нажатии, блоки заезжают с fade.

Экономика: старт **100** монет, доход за закрытую неделю **80**. Копилка при закрытии недели **не обнуляется**. Питомец меняется от **серии** решений (сытость, настроение, стадия 1–3), не от одной покупки.

## Архитектура

```
Ребёнок на телефоне / эмуляторе / в браузере
        │  тап, план, покупка, игра
        ▼
  lib/presentation  (экраны и виджеты)
        │  не считает экономику сам
        ▼
  GameController  ──► Economy (правила ТЗ)
        │                 │
        │                 ├─ план / факт / копилка
        │                 ├─ покупки need/want
        │                 ├─ задания
        │                 └─ мини-игры (макс. 80 монет / неделю)
        ▼
  ProfileStore  ──► shared_preferences (ключ finni_profile_v1)
        │
        └─ JSON профиля на устройстве, без сервера
```

- **UI не считает экономику.** Экраны зовут `GameController`, он зовёт `Economy` и пишет профиль.
- **Данные локальные.** Нет логина, почты, телефона, бэкенда.

```
finpet/
├─ lib/
│  ├─ main.dart
│  ├─ app/                      # тема, ассеты, адаптив, сплэш-гейт
│  ├─ domain/                   # модели, каталог, экономика
│  ├─ data/
│  │  ├─ storage/profile_store.dart
│  │  └─ audio/music_service.dart
│  └─ presentation/
├─ assets/images/               # комната, сплэш, логотип, PNG-виды (для создания питомца)
├─ assets/models/finni.glb      # одна 3D-модель на всех видах
├─ assets/audio/                # два трека
├─ android/                     # открывать из Android Studio
├─ test/
└─ .vscode/launch.json          # Finni (web) и Finni (Android)
```

### Технологии

- Flutter / Dart `^3.13.3`, Material 3
- `shared_preferences` — локальный профиль
- `model_viewer_plus` — GLB
- `audioplayers` — фон
- `flutter_animate` — появление блоков

### Правила в коде

| Правило | Значение | Где |
|---|---|---|
| Настоящие деньги / реклама / аккаунт / сервер | нет | весь клиент |
| Профиль | локальный JSON, `finni_profile_v1` | `ProfileStore` |
| Игровое имя | без почты и телефона | создание питомца |
| Демо-недели | закрывать без ожидания дней, по умолчанию вкл. | «Взрослым» |
| Шлюз «Взрослым» | `8 + 5` → `13` | `adult_screen.dart` |
| Мини-игры за неделю | не больше 80 монет | `Economy.maxMinigameCoinsPerPeriod` |
| Нужное в плане | не меньше 15 | `Economy.minNeedForPeriod` |
| Иконка валюты | ₽, не $ | `FinniIcons` |
| Адаптив | планшет от 600, широкий от 840 | `AppLayout` |
| Android minSdk | 26 | `android/app/build.gradle.kts` |
| Kotlin incremental | выкл. (кэш C: vs проект D:) | `android/gradle.properties` |

Тесты: `flutter test` — план не больше баланса, покупка без плана запрещена, минуса нет, копилка живёт между неделями. `widget_test` не вызывает `pumpAndSettle` (у питомца/анимаций нет конечного кадра).

## Как запустить в Android Studio

Это основной способ смотреть прототип на эмуляторе.

### Один раз на машине

1. Поставить **Android Studio** (с Android SDK) и **Flutter SDK**.
2. В Studio: плагин **Flutter** (подтянет Dart).
3. `flutter doctor` в терминале — зелёные Android toolchain и эмулятор.
4. **Device Manager** → AVD, лучше **API 26+**, **4+ ГБ RAM**. Проект и кэш Gradle/SDK часто лежат на разных дисках — это нормально.

### Открыть проект

1. `File → Open` → папка **`finpet`** (корень репозитория, не только `android/`, если просите Flutter-run).
2. Дождаться индексирования. В терминале Studio:
   ```powershell
   flutter pub get
   ```
3. Запустить эмулятор из Device Manager. В статус-баре должен появиться device (`emulator-5554` или другой номер — **не привязывайтесь к 5554**).
4. Сверху выбрать этот device, конфигурация запуска — `lib/main.dart` / Flutter.
5. Жмите **Run** (зелёный треугольник), не Debug, если сплэш зависает на логотипе Flutter: Debug иногда стартует с `--start-paused`.
6. Первая сборка долгая (Gradle + CMake для 3D/WebView). Повторные — быстрее.

### Hot Reload и Hot Restart

Пока приложение **уже запущено** на эмуляторе:

| Действие | Кнопка | Клавиши (Windows) |
|---|---|---|
| Hot Reload — мелкие правки UI | жёлтая молния | `Ctrl+\` |
| **Hot Restart** — новые виджеты, экраны, анимации | круглая стрелка | `Ctrl+Shift+\` |

После смены HUD, колец и блоков нужен именно **Hot Restart**. Полный Run — если Restart не подхватил ассеты, иконку приложения или Gradle.

Если на главном экране эмулятора иконка старая: `flutter pub get`, затем Run. Иконка лаунчера — `android/app/src/main/res/mipmap-*`.

### Если не собирается / зависает

- **Kotlin incremental / разные диски C: и D:** в репозитории уже `kotlin.incremental=false`. Не копируйте кэш Gradle руками между дисками.
- **Нет device `emulator-5554`:** смотрите `flutter devices`, запускайте тот id, который живой.
- **Вечный логотип Flutter:** Force Stop приложения на эмуляторе, затем снова **Run** (не Debug).
- **Порт / второй Flutter:** не держите два `flutter run` на один device.

Сборка из терминала, если Studio капризничает:

```powershell
flutter devices
flutter run -d <id_из_flutter_devices>
```

Остановка: в терминале `q`. Сброс прогресса — «Взрослым» → пример → «Сбросить тестовый профиль».

## Запуск в браузере / Cursor (дополнительно)

Сервер **сам не стартует**.

```powershell
flutter pub get
flutter run -d web-server --web-port 8080 --web-hostname 127.0.0.1
```

Открыть **http://127.0.0.1:8080**. В Cursor: F5, конфигурация **Finni**. **Finni (Android)** — эмулятор без фиксированного id.

Если `SocketException` на 8080 — старый `dart`/`flutter` ещё слушает порт.

## Что покрыто по ТЗ и чего не хватает

ТЗ PDF в git **не лежит** (`*.pdf` и исходники макетов в ignore). Ниже — сверка с тем, что заложено в коде и в требованиях прототипа.

### Уже есть

- Возраст и смысл: забота о питомце через решения «нужное / желаемое / копилка», без настоящих денег
- Нет рекламы, аккаунтов, сервера, почты и телефона
- Локальный профиль, демо-недели, шлюз для взрослого
- Дом: питомец, монеты, копилка, цель, настроение/сытость, текущее задание — не спрятаны в одном меню
- План и факт, покупки с запретом минуса и покупок без плана
- Задания по трём темам, словарь, обратная связь «Финни говорит»
- Мини-игры с потолком монет за период; награды игр не смешиваются с копилкой как «доход цели»
- Ошибки не фатальны: питомец не пропадает, неделю можно закрыть и поправить план
- Имя приложения по ТЗ: «Питомец Финни»

### Чего не хватает / нужно доделать

| Тема | Сейчас | Что сделать |
|---|---|---|
| Application ID | `com.example.finpet` | Свой id (не example) перед магазином |
| Подпись релиза | debug-ключи в `build.gradle.kts` | Свой keystore, не коммитить его |
| 3D-виды | одна GLB на всех, цвет — оттенок | Отдельные модели или материалы под вид/цвет, если ТЗ требует узнаваемость |
| Календарная неделя | демо по умолчанию, кнопка «Неделя» | Боевой режим: период по дням, демо только из «Взрослым» |
| RuStore / карточка | нет листинга | Скриншоты, описание 7–11, возраст, иконка 512, без «Flutter default» |
| Иконка | растр в mipmap (файл назывался svg) | Вектор/экспорт под все плотности по гайду магазина |
| Анимации | всегда вкл. | Выключатель «меньше движения» для чувствительных детей |
| Отчёт взрослому | краткая сводка | Больше тем, серий решений, без оценок «плохо» |
| Контент | несколько заданий и 4 цели | Добор ситуаций, если по объёму ТЗ мало |
| Устройства | эмулятор | Прогон на живом телефоне (WebView 3D, звук, жесты) |
| iOS | папка есть, не цель сдачи | Не обещать App Store, пока нет задачи |
| Документы ТЗ | PDF локально, не в git | Не коммитить PDF; хранить сверку в README |

Не раздувать сущности «просто так»: новые экраны и поля профиля — только если их нет в ТЗ и без них нельзя сдать.

## Что изменилось относительно прошлой версии

Прошлая опубликованная версия на `origin/Alex` / `origin/main` — web-прототип плюс README про план 3D. В этой версии на ветке `Alex`:

1. **Android** — сборка на эмулятор, minSdk 26, `kotlin.incremental=false` (кэш Kotlin не ломается, если pub-cache на C:, проект на D:).
2. **Имя** — «Питомец Финни» на лаунчере, не дефолтное Flutter/finpet.
3. **Иконка** — лиса и монета в mipmap.
4. **3D** — `finni.glb` на доме; питомец **стоит**, без autoRotate/autoPlay и подлёта.
5. **Заставка** — логотип до загрузки профиля, без 3D на сплэше (иначе вечный Flutter-логотип).
6. **Музыка** — два трека; с дома шторка громкости и выключение.
7. **Мини-игры** — к «Надо или хочу?» и «Лови монетки» добавлены баночки, копилка-ловец и пары.
8. **Дом** — HUD как у Talking Tom: крупные **цветные** круги (не мелкая иконка в белом круге), подписи, кольца статов.
9. **Прогресс** — одна круговая диаграмма до цели.
10. **Живость блоков** — press-scale, fade, кольца в плане/копилке/играх.

Web-запуск на `127.0.0.1:8080` сохранён. `main` отставал README-коммитами про план 3D — актуальная сверка здесь.
