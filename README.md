# 🐾 Питомец Финни (FinPet)

Игровой сервис финансовой грамотности для детей **7–11 лет**. Прототип по ТЗ
Департамента финансов города Москвы.

Ребёнок заботится о питомце: делит монеты на **нужное**, **желаемое** и **копилку**.
Настоящих денег, рекламы, аккаунтов и сервера нет. Профиль хранится только на устройстве.

Репозиторий: **https://github.com/AlexBelyakin/finpet** (private) · Стек: **Flutter / Dart · Material 3** · Запуск: **Windows, web-server `127.0.0.1:8080`**.
.

## 📐 Архитектура

### Как всё работает (поток данных)
```
Ребёнок в браузере / на телефоне
        │  тап, план, покупка, игра
        ▼
  lib/presentation  (экраны и виджеты)
        │  не считает экономику сам
        ▼
  GameController  ──► Economy (правила ТЗ)
        │                 │
        │                 ├─ план / факт / копилка
        │                 ├─ покупки need/want
        │                 ├─ задания
        │                 └─ мини-игры (макс. 80 монет / неделю)
        ▼
  ProfileStore  ──► shared_preferences (ключ finni_profile_v1)
        │
        └─ JSON профиля на устройстве, без сервера
```
- **UI не считает экономику.** Экраны зовут `GameController`, он зовёт `Economy` и пишет профиль.
- **Питомец меняется от серии решений**, не от одной покупки (сытость, настроение, стадия).
- **Данные локальные.** Нет логина, почты, телефона, бэкенда.

## 🚀 Запуск

Сервер **сам не стартует**. После изменений его поднимаешь руками.

### Предпосылки
- Flutter SDK (в этом проекте Dart `^3.13.3`)
- Клон репозитория, ветка `Alex` или `Ilya` для работы, `main` — общая
- Порт **8080** свободен

### Быстрый способ (Windows)
В папке проекта:

```powershell
flutter pub get
flutter run -d web-server --web-port 8080 --web-hostname 127.0.0.1
```

Открыть **http://127.0.0.1:8080** (в браузере либо IDE). Chrome сам не нужен.

### В Cursor
F5, конфигурация **Finni** — тот же web-server на `127.0.0.1:8080`.

### Тесты
```powershell
flutter test
```

`widget_test` не вызывает `pumpAndSettle`: у питомца бесконечная анимация.

## 🎮 Что умеет прототип

Заставка → знакомство («Это игра про монеты») → создание питомца
(кот / лис / птица, цвета персик / мята / небо / волна) → дом.

С дома:
- **Игры** — «Надо или хочу?» и «Лови монетки», монеты в копилку не идут; потолок **80 монет за неделю**
- **План** — разложить монеты: нужное / желаемое / копилка (нужное не меньше 15)
- **Задания** — короткие сценарии need / want / save
- **Покупки** — корм, вода, уход и «хотелки»; без плана купить нельзя, в минус уйти нельзя
- **Копилка** — цель и перевод с баланса
- **Прогресс** — история недель
- **Взрослым** — вход примером `8 + 5 = 13`: демо-недели, сброс профиля, сводка
- **Словарь** — подсказки по терминам

Стартовые монеты: **100**. Доход за закрытую неделю: **80**. Копилка при закрытии недели не обнуляется.

## ⚙️ Правила прототипа (как в коде)

| Правило | Значение | Где |
|---|---|---|
| Настоящие деньги / реклама / аккаунт / сервер | нет | ТЗ, весь клиент |
| Профиль | локальный JSON, ключ `finni_profile_v1` | `ProfileStore` |
| Игровое имя | без почты и телефона | создание питомца |
| Демо-недели | можно закрывать без ожидания дней | «Взрослым», по умолчанию вкл. |
| Шлюз «Взрослым» | `8 + 5` → `13` | `adult_screen.dart` |
| Мини-игры за неделю | не больше 80 монет | `Economy.maxMinigameCoinsPerPeriod` |
| Иконка валюты | ₽, не $ | `FinniIcons` |
| Адаптив | планшет от 600, широкий от 840 | `AppLayout` |

### Что «выключено» по дизайну
- **Нет бэкенда и аккаунтов** — всё на устройстве.
- **Нет настоящей 3D-модели** — пока PNG + «живой» 2D (bounce, тень, перспектива). Что сделать — ниже.
- **ТЗ PDF и исходники рисунков** (`*.pdf`, `/pict/`) в git не входят, в приложении лежат `assets/images/`.

## 📋 Что ещё не сделано

В README нет бэклога хакатона: ТЗ по экономике, экранам и локальному профилю уже в прототипе.
Открытая задача по картинке — **настоящий 3D-питомец**. Из PNG его не «выдавить»: это плоская картинка.

Сейчас `LivingPet` (`lib/presentation/widgets/finni_pet.dart`) крутит **2D PNG** матрицей (`rotateX` / `rotateY`, прыжок, тень). Для веба этого хватает как заглушки. Настоящий объём появится только после файлов моделей.

Плюс по рисункам: если у PNG непрозрачный фон, на комнате `bg_room.png` виден прямоугольник. Для 2D-запасного варианта лучше PNG **с прозрачностью**.

## 🧸 Как добавить 3D-моделек

Пока моделей в репозитории нет, пакет 3D в `pubspec.yaml` не подключаем. Сначала файлы, потом код.

### Формат
Нужен **glTF 2.0 в одном файле `.glb`** (mesh + материалы + текстуры внутри, без рядом лежащих `.bin` / `.png`).

| Формат | В это приложение |
|---|---|
| **`.glb`** | да — один ассет, Flutter web умеет показать |
| `.gltf` + `.bin` + текстуры | хуже: пачка файлов, легко сломать пути |
| `.png` / `.jpg` | это 2D, как сейчас; 3D из них не сделать |
| `.fbx` / `.obj` / `.blend` / `.ma` | исходники. Перед приложением конвертировать в `.glb` (Blender: File → Export → glTF 2.0 → GLB) |
| `.usdz` | для Apple AR, не наш веб-запуск |

Почему `.glb`: запускаемся **web-server**, без сервера и CDN. Файл лежит в репо и отдаётся как обычный asset.

### Какие файлы и имена
В коде 12 образов: **вид × цвет**. Имена должны совпасть с PNG, иначе `AppAssets` не найдёт модель.

Виды: `cat` (котёнок), `fox` (лисёнок), `bird` (птенчик).  
Цвета: `peach`, `mint`, `sky`, `wave`.

```
assets/models/
  pet_cat_peach.glb
  pet_cat_mint.glb
  pet_cat_sky.glb
  pet_cat_wave.glb
  pet_fox_peach.glb
  …
  pet_bird_wave.glb
```

Путь в коде (когда подключим): `assets/models/pet_${species}_${color}.glb` — как сейчас PNG в `AppAssets.pet`.

Можно сделать **3 модели** (кот / лис / птица) и красить материал под цвет — тогда в приложении нужна палитра. Проще для прототипа: **12 готовых `.glb`**, цвет уже в текстуре.

### Требования к самой модели
- glTF 2.0, **Y-up**, персонаж смотрит в камеру (как на текущих рисунках).
- Масштаб примерно «персонаж в кадре», не километры и не пылинка.
- Текстуры **внутри** `.glb` (не внешние URL — сервера нет).
- Вес: чем легче, тем лучше для веба; ориентир **до ~2–3 МБ на файл**, без 4k-текстур.
- Опционально клипы анимации в том же `.glb`: `idle` (дыхание), `tap` / `happy` (нажатие, хорошее настроение), `sad` (низкое настроение). Если клипов нет — оставим покачивание виджета, как сейчас.
- Без скачивания с интернета в рантайме.

### Куда в приложении
1. Сложить `.glb` в `assets/models/`.
2. В `pubspec.yaml` в `flutter/assets` добавить `- assets/models/`.
3. В `lib/app/assets.dart` — метод вроде `petModel(look)` рядом с `pet(look)`.
4. Подключить просмотрщик **для web**, который ест glTF (типичный вариант — обёртка над `<model-viewer>`, пакет вроде `model_viewer_plus`). Ставить пакет **после** того, как файлы уже в репо.
5. Новый виджет (например `PetModel3D`) вместо `Image.asset` внутри `LivingPet` / `FinniPetView`.
6. **PNG не удалять:** сетка «создать питомца», сплэш и запас, если `.glb` нет или web не поднял viewer.
7. Проверка там же, где гоняем прототип: `flutter run -d web-server --web-port 8080 --web-hostname 127.0.0.1` → дом, онбординг, смена вида/цвета.

Экономика, план, копилка и ТЗ от 3D **не меняются**. Меняется только картинка питомца.

## 🩹 Особенности окружения

- Запуск через **web-server + 127.0.0.1**, не через скрытый `localhost` и не автооткрытие Chrome: в Cursor Simple Browser иначе не цепляется.
- После правок **сервер не перезапускается сам** — `q`, затем снова `flutter run …`.
- Если `SocketException` на 8080 — старый `dartvm` ещё слушает порт.
- Экономика покрыта тестами: план не больше баланса, покупка без плана запрещена, минуса нет, копилка живёт между неделями.
