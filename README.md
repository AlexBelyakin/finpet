# Питомец Финни

Игровой сервис финансовой грамотности для детей **7–11 лет**. Прототип по ТЗ
Департамента финансов города Москвы.

Ребёнок заботится о питомце: делит монеты на **нужное**, **желаемое** и **копилку**.
Настоящих денег, рекламы, аккаунтов и сервера нет. Профиль хранится только на устройстве.

## Что есть в приложении

После иконки сразу арт-заставка (**~8 с**): телефон — `fon_zagruzki_fast.jpg`, планшет (shortest side ≥ 600) — `fon_zagruzki_planshet_fast.jpg`. Над полосой загрузки подписи нет. Дальше: приветствие → выбор персонажа → дом (или выбор локации, если это новый питомец).

- Нативная Android-заставка и адаптивная иконка
- Приветствие: «Привет! Это игра…», краткая инструкция, зелёная кнопка **Играть!**
- Выбор персонажа: **Финни** или **Нори** (два набора 3D-клипов)
- Шрифты только **Golos UI** (текст) и **PT Root UI** (заголовки)
- Две локации: **Теремок на лужайке** и **Усадьба у сада** (вторая открывается после 5 заданий). Смена места не сбрасывает монеты и прогресс. Новый персонаж начинает сначала
- Фон комнаты зависит от времени суток: утро 6:00–16:59, вечер 17:00–21:59, ночь 22:00–5:59; у телефона и планшета свои кадры
- Дом: комната, **3D biped Meshy** на полу, HUD вокруг питомца, облачко реплик по тапу (~7 с)
- После создания питомца один раз идут подсказки по значкам дома
- План на неделю: нужное / желаемое / копилка
- 17 заданий по трём темам (план, копилка, покупки), выбор и раскладка суммы
- После задания — похвала и сколько монет пришло
- 24 товара в магазине (12 нужного и 12 желаемого): без плана и в минус купить нельзя
- Копилка: 6 целей, положить / снять
- Прогресс: одно круговое кольцо до цели
- Пять мини-игр, потолок **80** монет за неделю; в копилку как доход цели не идут. «Копилка ловит» и «Лови монетки» рисуют падение одной кистью, на экране не больше 8 и 10 объектов
- Сытость −1 раз в 5 часов, настроение −1 раз в 8 часов. За ночь уходит 1–2 пункта, к «голоден» с обычных 70 нужно около недели без заботы
- Раздел «Взрослым»: пример `8 + 5 = 13`, демо-недели, сброс
- Меню дома: сменить локацию, новый питомец или выход из игры
- Словарь терминов
- Фоновая музыка и шторка громкости

Старт **100** монет, доход за неделю **80**. Копилка при закрытии недели не обнуляется.
Питомец меняется от **серии** решений, не от одной покупки.

## 3D-питомец

В `assets/models/finni/` и `assets/models/nori/` лежат **по 15 GLB** (риг Mixamo, `withSkin`). Это не один файл с 15 анимациями: каждый клип — своя модель.

На заставке прогревается один WebView и **4 частых клипа** выбранного тела (три idle и `react_joy`). Остальные подгружаются по событию. В RAM не больше 5 клипов.

Сырьё Meshy лежит в `meshy/finni` и `meshy/nori` с нормальными именами клипов и в git не входит (`/meshy/`, `/Meshy_AI_*/`).

### Idle (по кругу на одном слое, камера не крутится)

Клип идёт туда-обратно на одном `model-viewer`, без кроссфейда и без обрыва в конец файла.

| Клип | Когда |
|---|---|
| `idle_good` | сытость ≥ 40 и настроение ≥ 50 |
| `idle_thoughtful` | настроение < 50 |
| `idle_needs` | сытость < 40 |

### Разовые клипы (событие → выход на дом → клип → снова idle)

| Событие | Клип |
|---|---|
| Задание верно / неверно | `task_right` / `task_wrong` |
| Купил / не хватило монет | `buy_good` / `buy_no` |
| Положил в копилку / цель закрыта | `save_add` / `save_done` |
| Мини-игра | `react_joy` |
| Тап по питомцу | `react_joy` / `react_think` / `react_support` |
| Закрыл неделю / новая стадия | `react_joy` / `stage_baby` · `stage_teen` · `stage_adult` |

Порядок: действие только **ставит клип в очередь**. Пока игрок ещё в задании или магазине, клип грузится на скрытом слое. Анимация идёт, когда дом снова на экране.

Как устроено в коде:

1. `PetClips` (`lib/app/pet_clips.dart`) — имена файлов, idle/разовый, длительности, прогрев.
2. `GameController` — очередь (`queueEventClip`) и показ (`presentQueuedClip` / `playClipNow`).
3. `lib/data/pet/` — локальный HTTP-сервер, клипы в RAM, мост `prepare` / `resume` в WebView.
4. `lib/presentation/widgets/pet/` — один сеанс WebView, два слоя `model-viewer`: видимый и скрытый под загрузку.

Путь клипа: `assets/models/{finni|nori}/{clip}.glb`. В профиле это `PetLook.body`. Старый JSON без `body` читается как Финни.

Смена клипа не пересоздаёт WebView. Смена персонажа подменяет слой через `Finni.setBody`.

Новые GLB, шрифты, JPEG фонов и правки HTML/JS плеера — полный **Run**, не Hot Reload.

## Запуск в Android Studio

1. `File → Open` — корень репозитория **`finpet`** (не только папку `android/`).
2. В терминале Studio: `flutter pub get`.
3. Device Manager → запустить AVD.
4. Выбрать этот device. Конфигурация: `lib/main.dart`.
5. **Run** (зелёный треугольник). Не Debug, если на старте висит логотип Flutter: Debug иногда идёт с `--start-paused`.
6. Первая сборка долгая (Gradle, NDK, WebView для 3D). Дальше быстрее.

После старта с иконки: **фон загрузки (~8 с)** → приветствие и **Играть!** → выбор Финни или Нори → дом.

### Hot Reload / Hot Restart

Приложение уже запущено:

| | Кнопка | Windows |
|---|---|---|
| Hot Reload (мелочи UI) | жёлтая молния | `Ctrl+\` |
| Hot Restart (экраны, фон, виджеты) | круглая стрелка | `Ctrl+Shift+\` |

Смена фона загрузки, иконки, GLB, шрифтов, HTML плеера или Gradle — полный **Run**.

Номер эмулятора (`5554` / `5556`) не зашит: смотрите `flutter devices`.

### Если сборка падает

- Кэш Kotlin на разных дисках (проект на D:, pub-cache на C:): в репозитории уже `kotlin.incremental=false`.
- Нет device: `flutter devices`, запускайте живой id.
- Белый/Flutter-логотип: Force Stop на эмуляторе, снова **Run**.

Из терминала:

```powershell
flutter devices
flutter run -d <id>
```

Остановка: `q`. Сброс прогресса: меню дома «Новый питомец» или «Взрослым» → пример → «Сбросить тестовый профиль».

### Кэши Android Studio (диск C:)

Сборка и эмулятор пишут **не в папку проекта**, а в профиль Windows:

| Папка | Зачем |
|---|---|
| `%USERPROFILE%\.android\avd` | образы эмуляторов (~8 ГБ каждый) |
| `%LOCALAPPDATA%\Android\Sdk` | SDK, NDK, system-image |
| `%USERPROFILE%\.gradle` | кэш Gradle |
| `%LOCALAPPDATA%\Pub\Cache` | пакеты Flutter |

Дубликат AVD (`Medium_Phone` и `Medium_Phone_2`) занимает место дважды. Это не файлы репозитория.

## Запуск в браузере / Cursor

Сервер сам не поднимается.

```powershell
flutter pub get
flutter run -d web-server --web-port 8080 --web-hostname 127.0.0.1
```

Открыть http://127.0.0.1:8080. В Cursor: F5, конфигурация **Finni**. **Finni (Android)** — эмулятор без фиксированного id.

```powershell
flutter test
```

`widget_test` не вызывает `pumpAndSettle`: у питомца нет конечного кадра анимации. Заставка в тесте ждёт `AppSplash.hold` (8 с).

## Правила в коде

| Правило | Значение |
|---|---|
| Деньги / реклама / аккаунт / сервер | нет |
| Профиль | JSON на устройстве, `finni_profile_v1` |
| Имя игрока | без почты и телефона |
| Демо-недели | по умолчанию вкл., без ожидания дней |
| «Взрослым» | `8 + 5` → `13` |
| Мини-игры за неделю | не больше 80 монет |
| Нужное в плане | не меньше 15 |
| Валюта в UI | ₽ |
| Планшет | shortest side ≥ 600 |
| Заставка | 8 с, свой фон у телефона и планшета, без названия над полосой |
| Старт | приветствие → **Играть!** → Финни или Нори → локация → дом |
| Вторая локация | 5 выполненных заданий |
| Шрифты | только Golos UI и PT Root UI |
| 3D | два тела, клип от события, idle на одном слое, в RAM до 5 клипов |
| Шкалы | сытость −1 / 5 ч, настроение −1 / 8 ч |

Тесты: экономика, убывание шкал, каталог, локации, выбор idle, путь клипа Нори, очередь клипа до выхода на дом, первый экран «Привет! Это игра».
