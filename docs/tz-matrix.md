# 5.5 Матрица требований

Источник: PDF «6. Департамент финансов города Москвы», 17 стр., 2026.
Код: ветка `Alex`, `1.0.0+1`, сверка 23.09.2026.

Границы 2.7 (банки, реклама, чаты, ИИ, кабинет родителя) в прототип не входят.

Как читать колонку «Как проверено»:

- `flutter test` — автотест в `test/`, имя кейса как в файле.
- QA Ильи — 50 ручных кейсов на эмуляторе Pixel 6a (API 37), ветка `Ilya`, `qa/test_cases.md`. На `Alex` папка не копировалась.
- Ручной прогон — эмулятор и живой **POCO M8 5G** (Android 15, Snapdragon 6 Gen 3, 6,77″ 2392×1080, 25.09.2026).
- Нет автотеста — логика есть в модуле, отдельного `expect` нет.

Запуск автотестов:

```powershell
flutter test
```

На `Alex` 23.09.2026: 12 тестов, все зелёные (`widget_test` + домен). Живой WebView/GLB в `TestWidgetsFlutterBinding` не гоняется: вместо модели иконка.
