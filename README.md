# Питомец Финни

Игровой сервис финансовой грамотности для детей **7–11 лет**. Прототип по ТЗ
Департамента финансов города Москвы.

Ребёнок заботится о питомце: делит монеты на **нужное**, **желаемое** и **копилку**.
Настоящих денег, рекламы, аккаунтов и сервера нет. Профиль хранится только на устройстве.

## Возможности

После нажатия иконки сразу фон загрузки (**~5 с**): телефон — `fon_zagruzki.png`, планшет (shortest side ≥ 600) — `fon_zagruzki_planshet.png`.
Дальше по сценарию: знакомство → создание питомца → дом.

- Заставка с арт-фоном (~5 с, телефон и планшет), без 3D и без белого экрана Flutter
- Знакомство: «Это игра про монеты», три решения, ошибки можно чинить
- Питомец: кот / лис / птица, цвета персик / мята / небо / волна
- Дом: комната, **3D biped Meshy** на полу, HUD вокруг питомца
- План на неделю: нужное / желаемое / копилка
- Задания по трём темам
- Покупки: сначала нужное, без плана и в минус нельзя
- Копилка: цель, положить / снять
- Прогресс: одно круговое кольцо до цели
- Пять мини-игр, потолок **80** монет за неделю, в копилку как доход цели не идут
- Раздел «Взрослым»: пример `8 + 5 = 13`, демо-недели, сброс
- Меню дома: новый питомец или выход из игры
- Словарь терминов
- Фоновая музыка и шторка громкости

Старт **100** монет, доход за неделю **80**. Копилка при закрытии недели не обнуляется.
Питомец меняется от **серии** решений, не от одной покупки.

## 3D-питомец

В `assets/models/finni/` лежат **15 отдельных GLB** (риг Mixamo, `withSkin`). Это не один файл с 15 анимациями: каждый клип — своя модель.

Сырая папка Meshy в корень репозитория не входит (`/Meshy_AI_*/` в gitignore).

### Idle (по кругу, камера не крутится)

| Клип | Когда |
|---|---|
| `idle_good` | сытость ≥ 40 и настроение ≥ 50 |
| `idle_thoughtful` | настроение < 50 |
| `idle_needs` | сытость < 40 |

### Разовые клипы (событие → выход на дом → клип → снова idle)

| Событие | Клип |
|---|---|
| Задание верно / неверно | `task_right` / `task_wrong` |
| Купил / не хватило монет | `buy_good` / `buy_no` |
| Положил в копилку / цель закрыта | `save_add` / `save_done` |
| Мини-игра | `react_joy` |
| Тап по питомцу | `react_joy` / `react_think` / `react_support` |
| Закрыл неделю / новая стадия | `react_joy` / `stage_baby` · `stage_teen` · `stage_adult` |

Порядок: действие только **ставит клип в очередь**. Пока игрок ещё в задании или магазине, клип грузится на скрытом слое. Анимация идёт, когда дом снова на экране. Idle при этом не выгружается.

Как устроено в коде:

1. `PetClips` (`lib/app/pet_clips.dart`) — имена файлов, idle/разовый, длительности.
2. `GameController` — очередь (`queueEventClip`) и показ (`presentQueuedClip` / `playClipNow`).
3. `lib/data/pet/` — локальный HTTP-сервер, клипы в RAM, мост `prepare` в WebView.
4. `lib/presentation/widgets/pet/` — два слоя `model-viewer`: idle и action.

Первый заход на дом грузит idle один раз. Смена клипа не пересоздаёт WebView.

Новые GLB — полный **Run**, не Hot Reload.

## Запуск в Android Studio

1. `File → Open` — корень репозитория **`finpet`** (не только папку `android/`).
2. В терминале Studio: `flutter pub get`.
3. Device Manager → запустить AVD.
4. Выбрать этот device. Конфигурация: `lib/main.dart`.
5. **Run** (зелёный треугольник). Не Debug, если на старте висит логотип Flutter: Debug иногда идёт с `--start-paused`.
6. Первая сборка долгая (Gradle, NDK, WebView для 3D). Дальше быстрее.

После старта с иконки: **фон загрузки (~5 с)** → знакомство → питомец → дом.

### Hot Reload / Hot Restart

Приложение уже запущено:

| | Кнопка | Windows |
|---|---|---|
| Hot Reload (мелочи UI) | жёлтая молния | `Ctrl+\` |
| Hot Restart (экраны, фон, виджеты) | круглая стрелка | `Ctrl+Shift+\` |

Смена фона загрузки, иконки, GLB или Gradle — полный **Run**.

Номер эмулятора (`5554` / `5556`) не зашит: смотрите `flutter devices`.

### Если сборка падает

- Кэш Kotlin на разных дисках (проект на D:, pub-cache на C:): в репозитории уже `kotlin.incremental=false`.
- Нет device: `flutter devices`, запускайте живой id.
- Белый/Flutter-логотип: Force Stop на эмуляторе, снова **Run**.

Из терминала:

```powershell
flutter devices
flutter run -d <id>
```

Остановка: `q`. Сброс прогресса: меню дома «Новый питомец» или «Взрослым» → пример → «Сбросить тестовый профиль».

### Кэши Android Studio (диск C:)

Сборка и эмулятор пишут **не в папку проекта**, а в профиль Windows:

| Папка | Зачем |
|---|---|
| `%USERPROFILE%\.android\avd` | образы эмуляторов (~8 ГБ каждый) |
| `%LOCALAPPDATA%\Android\Sdk` | SDK, NDK, system-image |
| `%USERPROFILE%\.gradle` | кэш Gradle |
| `%LOCALAPPDATA%\Pub\Cache` | пакеты Flutter |

Дубликат AVD (`Medium_Phone` и `Medium_Phone_2`) занимает место дважды. Это не файлы репозитория.

## Запуск в браузере / Cursor

Сервер сам не поднимается.

```powershell
flutter pub get
flutter run -d web-server --web-port 8080 --web-hostname 127.0.0.1
```

Открыть http://127.0.0.1:8080. В Cursor: F5, конфигурация **Finni**. **Finni (Android)** — эмулятор без фиксированного id.

```powershell
flutter test
```

`widget_test` не вызывает `pumpAndSettle`: у питомца нет конечного кадра анимации. Заставка в тесте ждёт `AppSplash.hold` (5 с).

## Правила в коде

| Правило | Значение |
|---|---|
| Деньги / реклама / аккаунт / сервер | нет |
| Профиль | JSON на устройстве, `finni_profile_v1` |
| Имя игрока | без почты и телефона |

Тесты: экономика (план, минус, копилка), выбор idle, очередь клипа до выхода на дом, первый экран знакомства.

## ТЗ: что есть и чего не хватает

PDF ТЗ в git не лежит.

**Есть:** возраст и смысл (нужное / желаемое / копилка); нет рекламы и аккаунтов; локальный профиль; дом с 3D-питомцем, монетами, копилкой, целью, статами и заданием; план и факт; покупки с запретами; задания; мини-игры с потолком; словарь; шлюз взрослого; меню нового питомца и выхода; ошибки не фатальны; имя «Питомец Финни»; фон сразу после иконки.

**Доделать:**

| Тема | Сейчас | Нужно |
|---|---|---|
| Application ID | `com.example.finpet` | свой id перед магазином |
| Подпись релиза | debug-ключи | свой keystore, не в git |
| 3D | 15 GLB-клипов Meshy, события и idle | сжатие веса файлов |
| Календарная неделя | демо + кнопка «Неделя» | боевой период по дням |
| RuStore | нет карточки | скриншоты, возраст 7–11, иконка |
| Анимации | всегда вкл. | режим «меньше движения» |
| Отчёт взрослому | краткая сводка | больше серий решений, без «плохо» |
| Контент | несколько заданий, 4 цели | добор, если по объёму ТЗ мало |
| Устройства | эмулятор | живой телефон (3D WebView, звук) |
| iOS | папка есть | не цель сдачи, пока нет задачи |

Новые экраны и поля профиля — только если без них нельзя закрыть ТЗ.
